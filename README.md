# Babes & Babies

A hair and baby products shop in Ekim Town, Mkpat Enin, Akwa Ibom State, Nigeria, powered by Google Gemini AI.

## Live Site
https://babesandbabies-dcb39.web.app

## What it does
- AI Hair Stylist powered by Google Gemini that recommends hairstyles based on customer preferences
- AI Baby Advisor that recommends baby products based on baby age and needs
- Both assistants speak English and Nigerian Pidgin
- WhatsApp ordering and appointment booking

## Tech Stack
- Google Cloud Firebase Hosting
- Google Gemini API (gemini-2.5-flash)
- Cloudflare Workers (secure API backend)
- HTML, CSS, JavaScript
